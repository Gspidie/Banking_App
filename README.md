**Connect to MySQL**
    1) Open a terminal.
    2) Run `pip install mysql-connector-python` to install the mysql python connector.

**Create a Databse**
    1) Open MySQL Workbench.
    2) Create a new databse titled `banking_app`.

**Credentials**
    1) Navigate to authentication_utils.py, transaction_utils.py, and database.py.
    2) Replace the `password` paramater with your password.

**Add Tables**
    1) Navigate to database.py.
    2) Run the file to add a `accounts` and `transactions` table and a sample account to the database.

**Test**
    1) Navigate to authentication_test.py.
    2) Run the file to test the core functions.

**Main**
    1) Navigate to main.py.
    2) Run the file to begin the program, good luck!
